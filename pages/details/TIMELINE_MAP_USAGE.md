# 🗺️ 时间地图模式使用说明

## ✨ 功能概述

时间地图模式为你的details页面添加了强大的时间导航功能，让你可以像使用地图一样浏览所有动态的时间轴！

## 🎯 核心功能

### 📍 时间地图显示
- **左侧悬浮时间地图**：显示所有posts的时间分布
- **智能分组**：按日期自动分组（今天、昨天、本周等）
- **实时同步**：与cardSwipe完美同步，当前查看的post高亮显示
- **快速跳转**：点击任意时间点立即跳转到对应post

### 🔄 完全保留原功能
- ✅ **cardSwipe滑动**：所有原有的左右滑动功能完全保留
- ✅ **3D堆叠效果**：卡片的层叠、缩放、旋转动画不变
- ✅ **循环浏览**：无限循环浏览模式保持原样
- ✅ **手势操作**：所有触摸手势和交互保持不变
- ✅ **事件传递**：点赞、评论、预览等功能完全正常

## 🎨 界面特色

### 🗂️ 展开模式
- **时间筛选器**：今天、昨天、本周、全部四种筛选模式
- **日期分隔线**：清晰的日期分组，一目了然
- **详细信息**：每个post显示时间、作者、内容预览
- **类型图标**：文字和图片post用不同图标区分
- **当前指示器**：正在查看的post有呼吸灯效果

### 📱 折叠模式
- **简洁显示**：只显示当前post时间和位置
- **进度条**：可视化显示浏览进度
- **一键展开**：点击即可展开完整时间地图

## 🚀 使用方法

### 基本操作
1. **查看时间地图**：页面左侧自动显示时间地图
2. **展开/折叠**：点击地图头部的箭头图标
3. **快速跳转**：点击时间地图上的任意post
4. **时间筛选**：使用顶部筛选器按时间范围查看

### 高级功能
1. **智能滚动**：展开地图时自动滚动到当前post
2. **震动反馈**：点击跳转时提供触觉反馈
3. **Toast提示**：跳转时显示目标时间信息
4. **实时更新**：滑动卡片时地图实时更新高亮
