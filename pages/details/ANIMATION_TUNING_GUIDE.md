# 🎛️ 分享动画调参指南

## 📍 调参位置

文件：`pages/details/shareAnimationController.js`  
位置：文件顶部的 `ANIMATION_TUNING` 对象（第12-35行）

## 🎯 关键参数说明

### 1️⃣ **CONTENT_FADEIN_DELAY**（最重要！）

这个参数控制**内容淡入的时机**：

```javascript
CONTENT_FADEIN_DELAY: 500,  // 当前值 ✅
```

**可选值：**
- `0` → 图片到达后**立即**开始淡入（无缝衔接）
- `100` → 图片到达后**延迟 100ms** 再淡入（轻微停顿）
- `300` → 图片到达后**延迟 300ms** 再淡入（明显停顿）
- `500` → 图片到达后**延迟 500ms** 再淡入（从容优雅）✅ **当前配置**
- `-500` → 图片到达**前 500ms** 就开始淡入（优雅重叠）

### 2️⃣ **其他可调参数**

| 参数 | 说明 | 当前值 | 建议范围 |
|------|------|--------|----------|
| `OPENING_DURATION` | 开场动画时长 | 2500ms | 2000-3000ms |
| `APPRECIATION_DURATION` | 全屏欣赏时长 | 2000ms | 1000-3000ms |
| `IMAGE_TRANSITION_DURATION` | 图片移动时长 | 2000ms | 1500-3000ms |
| `CONTENT_FADEIN_DURATION` | 内容淡入时长 | **800ms** ⚡ | 500-2000ms |

## 🧪 快速调试流程

### 步骤1：修改参数
```javascript
const ANIMATION_TUNING = {
  // ...其他参数...
  CONTENT_FADEIN_DELAY: 0,  // ⚡ 改这里！
  // ...
};
```

### 步骤2：保存文件
按 `Ctrl+S` (Windows) 或 `Cmd+S` (Mac)

### 步骤3：刷新小程序
- 在微信开发者工具中，点击"编译"
- 或者在模拟器中下拉刷新

### 步骤4：查看控制台
动画开始时会输出详细信息：
```
🎬 ========== 启动分享动画 ==========
🎛️ ===== 当前动画参数配置 =====
⚡ 内容淡入延迟: 500 ms (延迟开始)
🌫️ 内容淡入时长: 800 ms
📅 ===== 计算后的时间线 =====
   T=0ms    : 容器显示
   T=500ms  : 开场动画开始
   T=3000ms : 开场动画结束
   T=5000ms : 图片开始移动
   T=7000ms : 图片到达目标
   T=7500ms : 内容开始淡入  ← 关注这个时间点！
   T=8300ms : 内容完全显现
   ...
```

### 步骤5：根据效果调整
- 如果觉得内容出现太早 → **增大** `CONTENT_FADEIN_DELAY`
- 如果觉得内容出现太晚 → **减小** `CONTENT_FADEIN_DELAY`
- 如果想要重叠效果 → 使用**负值**

## 🎨 推荐配置

### 配置A：从容优雅（当前 ✅）
```javascript
CONTENT_FADEIN_DELAY: 500,
CONTENT_FADEIN_DURATION: 800,
```
**效果**：图片到达后短暂停留，然后内容快速淡入，节奏从容又不拖沓

### 配置B：无缝衔接
```javascript
CONTENT_FADEIN_DELAY: 0,
CONTENT_FADEIN_DURATION: 800,
```
**效果**：图片到达的瞬间，内容开始淡入，无停顿感

### 配置C：优雅重叠
```javascript
CONTENT_FADEIN_DELAY: -500,
CONTENT_FADEIN_DURATION: 1200,
```
**效果**：图片还在移动时，内容就开始淡入，电影级过渡

## 💡 调试技巧

1. **小步调整**：每次调整 100-200ms，观察效果
2. **查看日志**：控制台会实时显示各阶段时间点
3. **多次测试**：同一配置测试2-3次，确保稳定
4. **记录最佳值**：找到满意的值后记录下来

## 🚨 注意事项

1. ⚠️ **不要修改 `CALCULATED_TIMELINE`**，它是自动计算的
2. ⚠️ **不要修改 `SHARE_ANIMATION_CONFIG.timeline`**，它使用计算值
3. ✅ **只修改 `ANIMATION_TUNING`** 对象中的参数即可

## 📞 遇到问题？

如果动画出现异常：
1. 检查是否只修改了 `ANIMATION_TUNING` 区域
2. 确保所有值都是**正整数**或**负整数**（不要用小数）
3. 查看控制台是否有错误信息
4. 恢复默认值重新开始
